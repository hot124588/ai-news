# 🤖 AI 新闻日报

每日AI资讯自动聚合。每天早晨自动抓取 HackerNews、GitHub Trending、开源中国、36氪 等来源的AI相关新闻，生成美观的静态日报页面。

## 每日更新

每天 **北京时间 08:00** 自动更新，打开即看最新AI资讯。

[🌐 访问 AI 日报 →](https://hot124588.github.io/ai-news/)

## 数据来源

| 来源 | 类型 | 内容 |
|------|------|------|
| HackerNews | 国际社区 | AI相关热门讨论 |
| GitHub Trending | 开源项目 | AI/ML趋势项目 |
| Show HN | 创意项目 | AI相关作品展示 |
| 机器之心 | 中文AI媒体 | 国内AI行业资讯 |
| IT之家 | 科技媒体 | AI科技动态 |

## 技术栈

- Python 脚本 → 抓取 + 生成静态 HTML
- GitHub Actions → 定时自动运行
- GitHub Pages → 免费托管
- **零成本**：无需服务器、无需API Key
